The state is one GitHub issue from a game project: its title, its body, and its labels.

Answer yes if what the issue describes stops a person from playing the game to its end: a
crash; the computer players stalling; a game that can no longer be won; a saved game that will
not load; or an order the player gives that can never succeed.

Answer no for everything else, however wrong it is: a wrong number or rule, a cosmetic or text
problem, missing polish, a test or tooling gap, or a refactoring.
